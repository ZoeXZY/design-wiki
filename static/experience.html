把同一道题，交给你使用的模型

这条规范，能用在这里吗？

从 4 个短情境中选一题，复制到模型的新对话，再把原回答带回来。你可以试一题，也可以完成四题。页面不调用 API，不消耗模型额度；模型端的使用按你自己的账号计费。

选择情境

每题使用一个新对话。关闭可见的联网、工具和记忆；平台不支持或不可知时，记在条件备注中。

这里使用公开规范的固定节选和构造情境，帮助观察模型如何判断。未提供标准答案，反馈也不等同于事实评分。

准备 / 本轮使用的模型

保存第一题后锁定本轮模型信息，避免把其他模型的回答混进来。换模型请开始另一轮；看不到的参数保持未知。

包含必要证据，不必把整个项目上传。复制受限时，可在文本框中全选复制。

02 / 带回模型的原回答

把体验记录带回项目

导出已保存的回答与反馈；不会自动上传。

记录属于人工回填体验，不冒充受控 API 实验；真实 token、响应耗时与结束原因在这里未知。记录尝试保存在当前浏览器本地，建议及时导出。请勿填写 API 密钥或私人资料。四题结果与正式 88 题测试分开分析。
